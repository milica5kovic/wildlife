# Wildlife
Wildlife is a full-stack web application that lists and manages activities happening in our city. Built using .NET (C#) for the backend and React (TypeScript) for the frontend, it follows a clean architecture with separate layers for API, Application, Domain, and Persistence.

🚀 Tech Stack

✅ Backend: .NET Core (C#), Entity Framework, SQL Server
✅ Frontend: React, TypeScript, HTML, CSS
✅ API: RESTful API using ASP.NET Core
✅ Database: SQL Server (via Entity Framework)
✅ State Management: React Context API / Redux
✅ Hosting & Deployment: Azure App Services (optional: Docker, CI/CD with GitHub Actions)

⚡ Features
    🏙️ List all activities happening in the city
    🔄 CRUD operations for activity management
    🔑 User authentication & authorization (JWT-based)
    📊 Modern UI with React & TypeScript
    🏗️ Scalable architecture following best practices
